# Week 3: Agribusiness Data Analysis and Visualization

## Project overview
This project demonstrates a practical data-analysis workflow for crop yield, seasonal patterns, operating costs, and market price/supply movements using Python, Pandas, and Matplotlib.

**Data note:** All values are illustrative sample data created for demonstration. They are not verified records from a real farm or market.

## Questions explored
- How does crop yield vary across the sample months?
- Which operating cost categories need further review?
- How do market price and a simplified supply index move over time?
- What can a scatter plot tell us about a possible relationship between fertilizer spending and yield?

## Project files
- `data/agribusiness_sample_data.csv` — illustrative dataset
- `notebooks/agribusiness_analysis.ipynb` — Python analysis and chart generation
- `visualizations/` — sample charts
- `report/Week_3_Agribusiness_Data_Analysis_Report.docx` — written report
- `requirements.txt` — dependencies

## Run the notebook
1. Install Python 3.10 or later.
2. Run `pip install -r requirements.txt`.
3. Open `notebooks/agribusiness_analysis.ipynb` in Jupyter Notebook and run cells from top to bottom.

## Methods
Data inspection, missing-value checks, descriptive statistics, line charts, bar charts, and scatter plots.

## Limitations
Charts show patterns but do not prove cause and effect. Use verified data, consistent units, sufficient observations, and local context before making real business decisions.
